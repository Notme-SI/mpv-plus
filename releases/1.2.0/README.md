### Windows

- 🎬 **Интерфейс**. Обновлён интерфейс плеера. Play/Pause и переходы по сериям находятся в центре кадра, а шкала времени появляется вместе с нижними кнопками. Значки Lucide и подсказки с горячими клавишами учитывают выбранную тему.
- 🖼️ **Сведения о видео**. В верхней панели отображаются логотип из TMDB, счётчик серий и сведения о видео и звуке. Для файлов с соответствующими метаданными отображаются HDR10+ и Dolby Vision.
- 📶 **Загрузка**. При загрузке плеер отдельно показывает скорость чтения, загрузку торрента и запас видео. Отчёт о загрузке сохраняет сведения о буфере и декодировании.
- 🛠️ **Обновления**. Окно обновлений оформлено в чёрно-золотых цветах CUB. После установки видны результаты по каждому компоненту и причины пропуска.
- 📦 **Компоненты**. Обновлены autocrop с доработками mpv+, mpv 2026-11-08-8bc468896e и FFmpeg cc583787b.

Установщик — установка с выбором папки и созданием ярлыков. Портативная версия — распакуйте архив целиком.

Для Lampa Desktop выбирайте `mpv.exe` из папки mpv+. Самостоятельный запуск — `mpv+.exe`. При повторной установке в прежнюю папку личные настройки сохраняются.

Контрольные суммы SHA-256 доступны в блоке **Assets** под именами файлов и в [файле контрольных сумм](https://github.com/Notme-SI/mpv-plus/blob/main/releases/1.2.0/SHA256SUMS.txt). Архивы **Source code** содержат исходники, а не готовый плеер.
