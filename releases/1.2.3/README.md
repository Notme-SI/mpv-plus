### Windows

- 🎬 **Интерфейс.** Светлые и тёмные прозрачные кнопки с тонким контуром. Переходы по сериям оформлены как Play/Pause, значок субтитров CC стал крупнее.
- ⌨️ **Подсказки.** Прежний шрифт, компактные отступы и сочетания заглавными буквами. Основные команды доступны и в русской раскладке.
- ⏭️ **Пропуск.** Компактные кнопки. Цвет меток на шкале можно поменять. По умолчанию используется золото CUB `#D8C39A`.
- 📶 **Загрузка.** В компактной строке отображается скорость со значком скачивания. Подробные данные о буфере доступны в статистике.
- 🖼️ **Lampa.** Служебное сообщение «Фильм не найден» больше не подменяет название. Плеер сохраняет ID карточки для загрузки названия и логотипа.
- 📚 **Руководство.** Сокращены инструкция на GitHub и памятка в сборке. Ссылка на загрузку ведёт к актуальному выпуску.
