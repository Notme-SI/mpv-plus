# Проверка 1.1.0

Обновлённый выпуск проверен 19 октября 2026 года на Windows x64.

- Связка рекапа и заставки проверена совместно с настоящей отрисовкой плашек. Новое уведомление не блокируется предыдущим.
- На локальном HTTP Range-стенде настоящий mpv пережил остановку передачи, получил статистику TorrServer, изменил буфер во время просмотра и перемотал вперёд/назад внутри кэша. После двух начальных HTTP-чтений новых запросов видео не возникло.
- Переключатель «Не скрывать интерфейс» проверен с настоящими Controls, Speed, Timeline и кнопками uosc: видимость до открытия видео, при скрытом курсоре и наведении на полосу, выключение и приоритет открытого меню. Отдельно проверены сохранение и повторный запуск.
- Все файлы компонентов, включая полный набор uosc, сверены с манифестом. Восстановлено исходное окончание файла ass.lua, вызывавшее ложное предупреждение «Локально изменён».
- `Test-Extensions.ps1`: синтаксис Lua, интерфейс, языки, названия, субтитры, восстановление потока, TorrServer, идентификация аниме и жизненный цикл плашек пропуска.
- Все скрипты окончательного payload вместе загружены настоящим mpv; оформление дополнительно проверено ASS-рендером.
- Локальное HTTP-видео с API TorrServer, задержанным на 4 секунды: видео открывается раньше метаданных. Таймаут не подставляет первый сезон и не включает пропуски по неверным координатам.
- Оба запускателя проверены с Unicode-данными, без дополнительных сведений, с повреждённым и слишком большим пакетом, а также сведениями другого файла. Открытие тестового файла не ждёт определения названия.
- Кэш текущего определения проверен на повторное использование, смену названия, поздние данные TorrServer и переключение файла. Независимые сведения сохраняют приоритет при конфликте.
- Архив проверен на целостность, безопасные пути, отсутствие личного состояния, совпадение исходников и хешей манифеста. Бинарники mpv/FFmpeg и каталог сверены с закреплённой базой 1.0.3.
- Патчи TheIntroDB, autochapters и TorrServer точно воспроизводят файлы поставки из закреплённых Git blobs.
- Setup собран Inno Setup 6.7.3 из проверенного payload. Установка поверх имеющейся пользовательской копии в этой проверке не выполнялась.
- Логика ссылок README проверена тестом. GitHub Actions повторяет сборку и проверки расширений в чистом окружении.

Реальный телевизор, все варианты оборудования и сторонних серверов не проверялись. Наличие правильных таймкодов зависит от внешних баз. Контрольные суммы готовых файлов находятся в `SHA256SUMS.txt`.
