# Проверка 1.1.0

Проверки выполнены 18 октября 2026 года на Windows x64.

- Разобраны все Lua-скрипты, JSON, Python и PowerShell. Проверены изменения, версии, чистые настройки и отсутствие личного состояния в публичном архиве.
- `Test-Extensions.ps1`: интерфейс, языки, названия, субтитры, восстановление потока, автообрезка, TorrServer, идентификация аниме, параметры пропуска и уведомления.
- Все скрипты вместе загружены настоящим mpv в headless-режиме, включая окончательный payload установщика.
- Жизненный цикл плашки проверен реальными событиями и таймерами mpv с тестовым видео и виртуальными размерами OSD: около 1,02 секунды до seek и 3,00 секунды после. Дополнительно проверены ручной клик до начала фрагмента, немедленное скрытие, буферизация и смена файла.
- Настоящий mpv с локальным HTTP-видео и намеренно задержанным API TorrServer: видео открывается до метаданных, таймаут не возвращает ложный первый сезон и не включает неверные пропуски.
- Оформление проверено ASS-рендером. Реальное окно, пользовательский поток и все сочетания оборудования/сторонних серверов в этой среде не проверялись.
- Пересборка патчей TheIntroDB, autochapters и TorrServer: проверены исходные Git blobs и точное применение всех изменений.
- Бинарники mpv/FFmpeg и снимок каталога сверены с базой 1.0.3 по SHA-256. ZIP проверен на целостность, пути, точное совпадение исходников и хеши манифеста.
- Setup собран Inno Setup 6.7.3. Готовый установщик проверен в отдельной папке: установка и хеши payload, оба запускателя, повторная установка с сохранением изменённых настроек и удаление с сохранением личных файлов.
- Необязательный мост проверен с API Lampa View: preload → IPC → окружение mpv. На штатном Windows PowerShell проверены установка в отдельную папку, резервная копия, повторная установка и отказ от изменения неподдерживаемой версии; исправлена кодировка сценариев.
- Логика обновления ссылок README проверена отдельным тестом. Workflow `Verify source and package` повторяет сборку из закреплённой базы и проверки в чистом окружении GitHub Actions.

Окончательные SHA-256 находятся в `SHA256SUMS.txt`. Проверки не гарантируют наличие правильных таймкодов у внешней базы для каждой раздачи.
