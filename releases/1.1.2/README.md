# mpv+ 1.1.2

Автоматическое определение аниме и упрощённое меню пропусков.

- Резервный поиск MyAnimeList через Jikan без ввода названий и MAL ID. Для официального API предусмотрен Client ID приложения.
- Проверка альтернативных названий, известного года, типа выпуска и номера серии. Подтверждённые локальные ID сохраняют приоритет; неоднозначное совпадение не запускает пропуск.
- Асинхронные запросы, кеширование и отбрасывание ответов после смены файла. При недоступности онлайн-каталога просмотр продолжается с локальной базой.
- Убраны ручной поиск таймкодов и пункт AniSkip с вводом аниме. «Заставки и титры» открывает настройки напрямую; Ctrl+I сохранён. Обновляются и старые персональные меню.

Windows 10/11 x64. ZIP — портативная сборка; Setup — установка с сохранением настроек.

Проверено на настоящем mpv: распознавание, неоднозначные результаты, кеш, смена серий и устаревшие ответы, пакет и установщик. Живой запрос Jikan из среды сборки завершился таймаутом. Доступность сервиса в конкретной сети не подтверждена; официальный API требует Client ID и ещё не подключён.
