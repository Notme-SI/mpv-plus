### mpv+ 1.1.1

- Плеер самостоятельно определяет видео по файлу и раздаче. Данные Lampa View помогают уточнить результат, а при противоречии с подтверждёнными данными не заменяют их.
- Передача карточки встроена: **отдельный мост устанавливать не нужно**. Обновите Lampa View и выберите `mpv.exe` внешним плеером в Lampa Desktop.
- Отсутствующие, повреждённые и относящиеся к другому файлу подсказки игнорируются. Дополнительная обработка не ставит сетевые запросы перед открытием видео.
- Исправлены ложные совпадения числовых имён серий и буквы диска Windows с названиями аниме. Локальный каталог повторно используется внутри каждого Lua-процесса.

[Установщик для Windows](https://github.com/Notme-SI/mpv-plus/releases/download/v1.1.1/mpv%2B-1.1.1-Setup.exe) · [Portable ZIP](https://github.com/Notme-SI/mpv-plus/releases/download/v1.1.1/mpv%2B-1.1.1.zip)

Для обычного запуска откройте `mpv+.exe`. Для Lampa Desktop выберите соседний `mpv.exe`. [Lampa View](https://github.com/Notme-SI/lampa-view) — версия 0.4.31 или новее.
