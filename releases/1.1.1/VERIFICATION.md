# Проверка 1.1.1

- 131 тест Lampa View, включая нативный код Lampa с немодифицированным Desktop API, отсутствие двойного запуска, отмену другим расширением, выбор качества, плейлист, смену карточки до запуска и возврат к штатному запуску при ошибке. Android и другие внешние плееры не получают новых аргументов.
- Настоящий mpv и совместимый запускатель `mpv.exe`: Unicode-карточка через аргумент запуска; отсутствие, повреждение и превышение размера данных; подсказка для другого файла. Проверено правильное сопоставление арки с TMDB/AniSkip.
- Открытие файла происходит до дополнительного разбора карточки. Отдельно измерено событие `file-loaded`: подсказка не добавляет ожидание сети до него. Это не измерение скорости вывода первого кадра на реальном оборудовании.
- Проверки расширений с готовым payload: неверные ID, сезон и серия, разные арки, явный сезон в папке обычного сериала, числовой файл `02.mkv`, недопустимое совпадение с буквой диска. Проверены заголовки, таймкоды, ручные настройки и запоздалые ответы.
- Все скрипты готового плеера совместно загружены в headless-режиме. Оформление отрисовано через ASS.
- Локальный HTTP-поток с API TorrServer, задержанным дольше таймаута: видео запрошено раньше метаданных, ложный первый сезон не возвращается после таймаута.
- ZIP, исходные файлы, манифест и конфигурация проверены по SHA-256. Персональные настройки и адреса не входят в выпуск.
- Установщик собран из проверенного payload. Сценарий установки не менялся; установка 1.1.1 поверх существующей пользовательской установки в этой среде не выполнялась.

Реальное окно Lampa Desktop и пользовательские потоки в этой среде не проверялись. Дополнительные данные помогают при неопределённости; они не могут гарантировать правильность исходной карточки, если файл и раздача не дают сведений для проверки. Доступность таймкодов зависит от внешних баз.
