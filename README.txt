mpv+ для Windows 10/11 x64

1. Установите плеер через Setup или распакуйте Portable ZIP целиком.
2. Запустите mpv+.exe и перетащите видеофайл или прямую ссылку в окно.
3. Для Lampa Desktop выберите mpv.exe из папки mpv+ в настройках внешнего плеера.

Правая кнопка мыши открывает меню. Пробел ставит на паузу, стрелки перематывают, F8 открывает плейлист. CTRL+I открывает настройки пропуска, ALT+A переключает автопропуск.

TorrServer настраивается через «Обслуживание → Настроить TorrServer».
Обновление плеера открывается через «Обслуживание → Обновить mpv+».
