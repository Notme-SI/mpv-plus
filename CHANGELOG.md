# Изменения

## 1.2.4 — 2026-11-11

- Исправлено распознавание сериала из Lampa, когда имя файла содержит год выпуска последующего сезона. Совпадающая карточка сохраняет ID для названия, логотипа и таймкодов после проверки названия, ID, сезона и серии.

## 1.2.3 — 2026-11-09

- Варианты значков переименованы в «Светлые» и «Тёмные» с описаниями «Светлое и прозрачное» и «Тёмное и прозрачное».
- Стеклянное оформление стало заметно прозрачнее: ослаблены тёмная подложка и сплошной белый слой, блики сосредоточены у краёв. Тонкий контур сохранён.
- Значок субтитров CC увеличен внутри прежнего фона кнопки.
- Исправлено измерение текста: прозрачный отступ последнего символа в libass больше не расширяет подсказки и информационные плашки. Подсказки снова используют основной шрифт плеера.

## 1.2.2 — 2026-11-09

- Уменьшен фон кнопок в обоих оформлениях. Контуры рисуются с повышенной точностью, а переходы по сериям используют светлый диск и тёмный символ, как Play/Pause.
- Новый тонкий значок субтитров CC. Уплотнены подсказки без сочетания клавиш; подсказка скорости использует слово «Скролл».
- При загрузке компактная строка показывает только скорость и значок Lucide Arrow Down to Line. Сведения о запасе видео остаются в статистике.
- Служебная заглушка Lampa «Фильм не найден» больше не подменяет название сериала. Сохраняется ID карточки для загрузки настоящего названия и логотипа.

## 1.2.1 — 2026-11-08

- Сочетания клавиш в подсказках показаны заглавными буквами. Команды меню, TorrServer, закрепления окна и полного экрана доступны в русской раскладке.
- Вернулась булавка для режима «Поверх всех окон», увеличен значок субтитров. Счётчик и подпись серии используют тот же серый цвет, что видео и аудио.
- Цвет меток пропуска по умолчанию — золото CUB #D8C39A. В настройках полосы перемотки доступны готовые цвета и ввод своего HEX.
- Кнопки пропуска и автопропуска подогнаны по ширине текста и оформлению плеера. Подсказки панели учитывают их положение.

## 1.2.0 — 2026-11-08

- Обновлён интерфейс плеера. Play/Pause и переходы по сериям находятся в центре кадра, а шкала времени появляется вместе с нижними кнопками. Значки Lucide и подсказки с горячими клавишами учитывают выбранную тему.
- В верхней панели отображаются логотип из TMDB, счётчик серий и сведения о видео и звуке. Для файлов с соответствующими метаданными отображаются HDR10+ и Dolby Vision.
- При загрузке плеер отдельно показывает скорость чтения, загрузку торрента и запас видео. Отчёт о загрузке сохраняет сведения о буфере и декодировании.
- Окно обновлений оформлено в чёрно-золотых цветах CUB. После установки видны результаты по каждому компоненту и причины пропуска.
- Обновлены autocrop с доработками mpv+, mpv 2026-11-08-8bc468896e и FFmpeg cc583787b.

## 1.1.3 — 2026-11-03

- Добавлено графическое окно обновлений с вкладками «Плеер mpv+» и «Компоненты»: версии, изменения выпуска, состояние модулей, прогресс и журнал. Видимое окно PowerShell больше не используется.
- Вся сборка обновляется через проверенный установщик с сохранением настроек. Проверка выполняется без закрытия плеера; компоненты устанавливаются с проверкой совместимости и повторным запуском.

- Исправлено обновление TheIntroDB: доработки mpv+ перенесены на исходник 2.1.0 с API v4 и обработкой лимитов запросов. Отдельные патчи сохраняют изменения исходника вне затронутых участков; конфликты по-прежнему останавливают обновление компонента.
- Убрана служебная строка прогресса веб-запроса PowerShell из журнала обновления.

- Обновлены mpv (2026-11-03-0d4aab5cf6) и FFmpeg (ec887b13a); сборщик проверяет и использует зафиксированные двоичные компоненты.

## 1.1.2 — 2026-10-20

- В «Обслуживание» добавлена текущая версия mpv+; нажатие открывает соответствующий релиз на GitHub.
- Резервный поиск аниме в каталоге MyAnimeList через Jikan: проверка альтернативных названий, года, типа выпуска и номера серии. Неоднозначные результаты не запускают автоматический пропуск.
- Распознавание работает автоматически, без ввода названий и MAL ID. Для официального API предусмотрен Client ID приложения; без него используется Jikan.
- Убраны пункты ручного поиска аниме и таймкодов. «Заставки и титры» открывает настройки напрямую, без одноимённого вложенного пункта; старые сохранённые меню исправляются при показе.
- Онлайн-поиск работает асинхронно, кеширует ответы, ограничивает частоту запросов и игнорирует ответы для уже закрытого файла. Локальные подтверждённые совпадения остаются приоритетными.

## 1.1.1 — 2026-10-20

- Стеклянное оформление меню и выделения строк согласовано с кнопками плеера. Обновлены скриншоты интерфейса.
- Из меню убраны отдельные команды пропуска заставки, рекапа и титров. Настройки пропусков и экранная кнопка сохранены; анонсы не пропускаются и не отмечаются на шкале.
- Постоянная нижняя панель, строка буфера и статистика по умолчанию выключены; каждую настройку можно включить отдельно.
- Улучшено определение названий серий и аниме-арок по данным раздачи; названия соседних серий появляются в плейлисте после загрузки сведений о сезоне.
- При сетевом перетаскивании шкалы выполняется один точный переход после отпускания кнопки. Строка буфера показывает пакеты mpv, отдельно от кеша TorrServer. Добавлен отчёт о загрузке в меню «Сеть и буфер».
- Исправлены отмена восстановления потока и повторное воспроизведение последних секунд после завершения серии.
- Поиск таймкодов AniSkip и GuessIt выполняется асинхронно; при закрытии отменяются фоновые запросы, а поздние ответы не запускают новые попытки.
- Исправлены повторные проверки автообрезки при первом открытии и переключении серий.

## 1.1.0 — 2026-10-18

- Сетевая статистика стала компактнее и прозрачнее. Строка буфера вынесена над перемоткой; её видимость и видимость статистики переключаются независимо в настройках интерфейса. Полные значения остаются в меню «Сеть и буфер».
- В строку под названием добавлены язык, каналы и битрейт аудио. В статистике показаны исходное разрешение, профиль видео, действующий аппаратный декодер, частота экрана, параметры звука, потери кадров и синхронизация.
- Распознаются штатные ссылки TorrServer `/stream/имя-файла`; запросы статистики сохраняют авторизацию и префикс прокси.
- Сомнительные сетевые отметки конечных титров в первой половине видео и противоречащие друг другу интервалы не вызывают автопропуск. Явные главы файла остаются приоритетными.

- Исправлен автопропуск соседних рекапа и заставки. На экране остаётся одна плашка; результаты соседних пропусков объединяются и видны три секунды после перехода. Добавлено короткое затухание видео без изменения громкости.
- Восстановлена полноценная сетевая статистика при каждом открытии, перемотке и ожидании данных. Штатные сведения загрузчика TorrServer и показатели плеера объединены в одну панель. Запросы выполняются асинхронно и прекращаются после восстановления.
- Буфер меняется без перезагрузки файла, режим «Авто» учитывает источник. Добавлен обратный буфер; перетаскивание ползунка объединяет частые сетевые перемотки с точной финальной позицией.
- В меню «Интерфейс → Панель плеера» добавлен сохраняемый переключатель «Не скрывать нижнюю панель».
- Постоянной остаётся только нижняя панель: кнопки, скорость и полоса перемотки. Верхняя панель и громкость сохраняют штатное затухание. Исправлен лишний значок звука в левом верхнем углу; пустой экран не показывает «(unavailable)». Убрано ложное предупреждение о локальном изменении uosc в чистой сборке.
- Плашки пропуска появляются за секунду до фрагмента. Автопропуск ждёт отрисовки плашки; подтверждение остаётся 3 секунды после перемотки, ручной пропуск скрывает плашку сразу.
- Круглые кнопки, стеклянное оформление и единый тёмный полупрозрачный фон обычных кнопок, названия и тегов. Исправлены исчезающие значки и артефакты текста.
- Возвращён значок булавки: закрепление поверх приложений без изменения размера окна.
- Исправлены координаты аниме-сезонов и получение контекста текущей раздачи без обязательного Desktop-моста. Разрешение 1920×1080 не принимается за сезон и серию.
- Открытие потока больше не ждёт метаданные TorrServer. Таймаут API не подставляет первый сезон и не запускает автопропуск по ложным координатам.
- Раздельные настройки типов автопропуска, память громкости и раздельные метрики сервера и плеера.
- Обновлены руководство, проверки, воспроизводимая упаковка и установщик. Личные данные исключены из поставки.

- Самостоятельное определение видео сверяет дополнительные сведения с исходным файлом. Чужие и некорректные данные не блокируют просмотр.
- Исправлено распознавание файлов вида `02.mkv`; повторные проверки используют результат для текущего файла и пересчитываются при получении данных TorrServer.
