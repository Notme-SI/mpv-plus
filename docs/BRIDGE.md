# Данные Lampa в mpv+

Начиная с **mpv+ 1.1.1 и Lampa View 0.4.31** отдельный мост устанавливать не нужно.

1. Установите [mpv+](https://github.com/Notme-SI/mpv-plus/releases/latest) и [Lampa View](https://github.com/Notme-SI/lampa-view).
2. В Lampa Desktop выберите внешний плеер `mpv.exe` из папки mpv+.

Готово. Плеер работает самостоятельно, а сведения карточки помогают проверить название, сезон и серию. При противоречии с подтверждёнными данными файла карточка их не заменяет. Запросы к каталогам и TorrServer выполняются в фоне.

Без Lampa View плеер продолжает определять видео самостоятельно. Отсутствие дополнительных данных не препятствует просмотру. При неоднозначном результате автопропуск не подставляет случайный сезон.

На Android TV с Just+ этот Windows-мост не используется.

Архив `lampa-mpv-bridge.zip` из версии 1.1.0 для новой связки не требуется. Если он уже установлен, обновлённый плагин продолжит работать; повторно устанавливать архив не нужно.
