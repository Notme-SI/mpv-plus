# Дополнительные данные при запуске

mpv+ самостоятельно определяет видео по имени файла и данным TorrServer. Отдельная установка моста не требуется.

Приложение, запускающее плеер, может передать сведения о выбранном видео. Плеер принимает их только для точной ссылки текущего файла и сверяет с названием, идентификаторами, сезоном и серией. Подтверждённые данные исходного файла сохраняют приоритет. Некорректные или отсутствующие сведения не препятствуют просмотру.

Для обычного использования достаточно [инструкции](USAGE.md). Формат приёма для разработчиков находится в `portable_config/extensions/lampa_context.lua`; он не запускает сетевые службы и не требует изменений приложения плеера.
