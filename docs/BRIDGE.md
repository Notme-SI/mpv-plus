# Мост Lampa Desktop

**Для обычного просмотра он не нужен.** Если видео открывается и определяется правильно, ничего дополнительно устанавливать не нужно.

Мост передаёт плееру название, ID, сезон и серию из карточки Lampa. Это помогает, когда по имени файла нельзя однозначно определить сериал. Сам по себе мост не добавляет отсутствующие в базах таймкоды.

Поддерживается **Lampa Desktop 1.6.0-ac3.24 для Windows**. Для другой версии этот архив не устанавливайте: установщик проверяет совместимость.

1. Подключите [плагин Lampa View](https://github.com/Notme-SI/lampa-view).
2. Скачайте [lampa-mpv-bridge.zip](https://github.com/Notme-SI/mpv-plus/releases/download/v1.1.0/lampa-mpv-bridge.zip) и распакуйте целиком.
3. Закройте Lampa и дважды нажмите **Подключить к Lampa.cmd**. Подтвердите запрос Windows.
4. Откройте Lampa. В настройках внешнего плеера выберите `mpv.exe` из папки mpv+.

Готово. Папку `_service` отдельно копировать не нужно. Установщик сохраняет резервную копию приложения в `_service/backups`; при обновлении Lampa мост может потребоваться подключить повторно.
